Project overview

One system for sensing, monitoring and action

The project is designed for indoor environments such as classrooms, laboratories, offices and residential rooms. It combines low-cost sensors, wireless communication, cloud monitoring and basic automation.

01

Monitor

Capture temperature, humidity, light level and human presence in real time.

02

Connect

Use the ESP32's wireless connection to send sensor data to the cloud.

03

Automate

Use simple rules such as presence + low light to switch a low-voltage LED.

Main controller. Reads sensors, makes local decisions and communicates wirelessly.

Measures the surrounding light level so the system can identify darker conditions.

Detects human movement or presence in the monitored area.

W

Wireless link

Moves sensor telemetry from the ESP32 to the cloud for remote monitoring.

A

Automation

Turn data into a simple action

The demonstration version uses a low-voltage LED to show how sensor conditions can trigger a response.

Example rule

Person detected + low light → LED ON

Enough light OR no person → LED OFF

The exact light threshold is calibrated from the LDR readings in the demonstration environment.

What the judge can see

  • Cover the LDR to simulate darkness.
  • Move in front of the PIR sensor.
  • Watch the LED switch on automatically.
  • Shine a phone flashlight or step away and observe the response.
